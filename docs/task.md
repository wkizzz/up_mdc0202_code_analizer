## Исходная формулировка (новое задание)

Модуль статического анализа исходного кода со следующими возможностями:

1. **Настраиваемые правила** — стандартные (встроенные) + свои (через YAML/JSON).
2. **Отчёты в SARIF и JSON** — для интеграции с IDE и CI.
3. **Интеграция с CI** — блокировка при наличии находок уровня CRITICAL.
4. **Игнорирование ложных срабатываний** — через inline-комментарии
   (`# analyzer: disable=RULE_ID` или `# noqa: RULE_ID`).

- CI-конвейер (GitHub Actions), проходящий на `main`.
- Релиз `v0.1.0` с Release Notes.
